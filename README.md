# DMD941-Desafio-Practico-2

Proyecto académico de Data Warehouse y Business Intelligence desarrollado con SQL Server, Analysis Services (SSAS) y Power BI. Incluye la restauración de AdventureWorksDW2022, el diseño y procesamiento de un cubo OLAP y la creación de dashboards interactivos para analizar las ventas por producto, período y territorio.
